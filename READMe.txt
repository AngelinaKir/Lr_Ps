1. СИСТЕМНЫЕ ТРЕБОВАНИЯ
OSPanel (или OpenServer) c поддержкой PHP и MySQL
PHP 8.0 или выше
MySQL 5.7 или выше
Веб‑браузер: Chrome / Firefox / Edge
2. УСТАНОВКА
2.1. Копирование проекта

Скопируйте папку SATEMATE.local в директорию (по умолчанию):
D:\OSPanel\home\
В итоге путь должен быть:
D:\OSPanel\home\SATEMATE.local
(Если у вас OSPanel на диске C, путь будет аналогичный: C:\OSPanel\home\SATEMATE.local.)

2.2. Настройка домена в OSPanel

Запустите OSPanel.
Откройте настройки доменов.
Добавьте домен satemate.local (если его ещё нет), указав корневую папку:
...\OSPanel\home\SATEMATE.local
2.3. Создание базы данных

Откройте phpMyAdmin:
http://localhost/phpmyadmin
Создайте новую базу данных:
Имя БД: ladesign
Кодировка: utf8mb4_general_ci
Импортируйте дамп структуры и данных:
В меню выберите созданную БД ladesign
Перейдите во вкладку «Импорт»
Выберите файл дампа (например: database/ladesign.sql из корня проекта)
Нажмите «Вперёд» и дождитесь окончания импорта
3. НАСТРОЙКА ПОДКЛЮЧЕНИЯ К БД
Файл подключения: includes/db.php

Настройки по умолчанию (из проекта):

define('DB_HOST', '127.127.126.26');
define('DB_PORT', 3306);
define('DB_NAME', 'ladesign');
define('DB_USER', 'root');
define('DB_PASS', '');
Если вы поднимаете проект на другом компьютере, при необходимости измените:
DB_HOST – обычно 127.0.0.1 или localhost
DB_PORT – по умолчанию 3306
DB_NAME – имя созданной базы (ladesign)
DB_USER / DB_PASS – логин и пароль MySQL на вашей машине
После изменения сохраните файл includes/db.php.
